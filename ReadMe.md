# 💫 About Me:
I am a Data Science undergraduate at Multimedia University (MMU) moving from classical machine learning into **AI engineering**. I'm currently interning as an AI engineer, building LLM-powered tools that go from prototype to real users.

I love diving into datasets to solve interesting quantitative problems, whether it's modeling tournament bracket simulations or exploring complex user-behavior patterns, and I'm now applying that curiosity to building reliable, production-minded AI systems.

---

# 🚀 What I'm Working On:

- **Invoice Extraction & 3-Way Matching:** A pipeline that extracts data from supplier invoices and delivery orders using prompt-based LLM extraction (Gemini on Vertex AI), stores it in structured tables synced with Google Drive and Sheets, and reconciles it against purchase orders. Built with a Streamlit UI and demoed to the procurement team for feedback.
- **Project Guardrail (RAG):** A retrieval-augmented generation tool for site inspection observations. It searches past observations, generates practice write-ups, and retrieves related inspection and rectification photos from cloud storage. Backed by Cloud SQL, deployed on Cloud Run, and iterated on user feedback (e.g. location-aware search boosting).
- **Data Science & AI Club (DATAI):** Leading the branding and social media team.
